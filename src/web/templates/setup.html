Chrome Extension Setup

Follow these three steps to connect the Stride Chrome extension to your account.

1

Install the Extension

Load the Stride Chrome extension from the chrome-extension/ folder in the project.

  1. Open Chrome and navigate to chrome://extensions
  2. Enable Developer mode using the toggle in the top-right corner
  3. Click "Load unpacked"
  4. Select the chrome-extension folder from the Stride project directory
Once installed, you'll see the Stride icon in your Chrome toolbar. You may need to click the puzzle piece icon and pin it.
2

Copy Your Credentials

{% if api_key %} Ready {% endif %}

Your credentials are pre-generated. Copy each value below and paste them into the extension settings.

3

Connect the Extension

  1. Click the Stride icon in your Chrome toolbar
  2. Click the gear icon to open extension settings
  3. Paste the Server URL and API Key from Step 2
  4. Click Save
Once connected, visit any LinkedIn profile, company, or job page and click the Stride icon to import data into your tracker.
